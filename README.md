# SHakti – Women's Safety Awareness and Support Website

## About the Project
SHakti is a web-based platform designed to promote women's safety awareness and provide useful information, guidance and support resources.

## Features
- Women's safety awareness resources
- Fundamental rights and legal support information
- Emergency support information
- Cyber safety awareness
- Workplace safety information
- Interactive quiz
- User surveys and feedback submission

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Project Structure
- `backend/` – Server and API functionality
- `css/` – Website stylesheets
- `js/` – JavaScript functionality
- `index.html` – Homepage
- Other HTML files – Website sections

## How to Run Locally
1. Install Node.js.
2. Open the backend folder in a terminal.
3. Run `npm install`.
4. Run `node server.js`.
5. Open `http://localhost:5000` in your browser.

## Project Purpose
To make women's safety information more accessible and encourage awareness through an interactive and informative platform.
